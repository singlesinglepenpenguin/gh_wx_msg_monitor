# 群接龙更新工具 · 怎么用

这个工具就是帮你：看微信群里的接龙，自动把 Excel 里对应的格子清掉，并另存一份新表。

收到 Windows 交付包后，完整解压到可写文件夹。第一次双击 **`setup.bat`**，以后双击 **`start.bat`**。交付包已包含 Python、界面和微信读取所需依赖，无需安装 Python、输入命令、使用 AI 或提供密钥。不要只复制 exe 或 bat。

如果使用源码文件夹（没有 `GroupMessageMonitor.exe`），才需要含 Tkinter 的 Python 3.10+；首次 `start.bat` 会自动调用 `setup.bat` 安装依赖。

---

## 平时怎么更新

1. 微信登录好
2. 双击 `start.bat`
3. 选好通讯录、要更新的表
4. 新表第一次用，填一下开始时间；用过的表一般不用填
5. 点「开始更新」
6. 看结果：打开最新结果 / 查看最新记录

需要定时监控时，勾选「保持运行时，每天 09:00、15:00 自动更新」。这个选择会保存；以后双击 `start.bat` 会继续使用已保存的文件、读取进度和自动更新设置。工具和电脑需要保持运行。

它会另存新表，不会直接改坏你原来那份。

## 第一次连微信（Windows）

工具会引导完成一次性连接；管理员授权和微信本人登录需要你确认。现有有效凭据可直接用于日常读取。

1. 双击 `setup.bat`，自动检查依赖并打开「微信连接设置」。也可从 `start.bat` 主界面进入这里。
2. 未登录微信时，点「打开微信」完成本人登录，再点「识别当前账号」。界面会通过 Windows 文件占用确认当前账号，无需辨认磁盘账号目录。
3. 等微信聊天同步完成、保存草稿后，点 **「自动获取密钥并连接微信」**并确认。工具请求微信正常退出，随后自动开始连接；若微信拒绝退出，向导会提示从微信自己的托盘菜单退出，检测到退出后自动继续。
4. Windows 授权点「是」，在弹出的微信窗口登录同一账号。短暂停留在「正在进入」时等候，不要重复点连接。
5. 显示「连接完成」后，工具会正常重新打开微信。完成本人登录并保持运行，以便同步新消息；点「完成，返回主界面」开始使用。

成功之后，日常就不用再初始化了。

首次使用时账号栏为空，需要主动点击「识别当前账号」。识别出账号不代表已经取得读取凭据，仍需完成一次性连接。

## 核对机构与首次验收

1. 选择通讯录和目标 Excel。工具每次更新都重新读取当前目标表的机构行与姓名列，增减后须保存并关闭 Excel。成功更新后默认接续新生成的表，请确认修改的是当前选中的版本。
2. 核对目标表确实含有本次接龙的机构。机构应位于消息标题主语位置；格式不明确时可使用独立一行「机构：完整机构名称」。日期、表情和正文提及不会作为机构归属依据；多家机构或证据冲突时不会自动清空。
3. 填写覆盖测试消息的开始时间，点击「开始更新」。打开生成表与本轮记录，按“机构、姓名、单元格、接龙原文”核对实际删除；原本已空会单独记录。
4. 如果使用随附测试用的原始表，其机构列没有富国、国联安、建信，而时间段内只有这三家的接龙，则预期是 0 格并提示未匹配。要验证实际清空，请另存测试副本，按实际业务补齐机构行、姓名列及待清空内容，再选该副本更新；不要修改两个原始测试文件。
5. 无法匹配的机构消息会留待下轮复核。补齐目标表后可以复核；不需要重新取微信密钥。新安装包未包含任何历史消息，必须由客户自己的微信完成首次读取。

## 卡住了

| 情况 | 怎么办 |
|---|---|
| 暂停在「正在进入」 | 先看向导的等待提示，数据库校验可能暂时暂停微信；不要重复初始化。超时后按错误编号处理 |
| 提示微信仍在运行 | 先等同步完成，再从托盘退出；工具不会自动强制关闭微信 |
| Excel 被占用 | 先关掉 Excel / WPS 里那张表 |

还不行：把报错原文发我们；别发 `data/local_data` 文件夹。
