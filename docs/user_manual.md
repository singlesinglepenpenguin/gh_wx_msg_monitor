# 群接龙更新工具 · 怎么用

这个工具就是帮你：看微信群里的接龙，自动把 Excel 里对应的格子清掉，并另存一份新表。

收到 Windows 交付包后，解压并保留完整文件夹，双击 **`start.bat`**。交付包已包含 Python 和运行依赖，无需安装 Python，也无需运行 setup。

如果使用源码文件夹（没有 `GroupMessageMonitor.exe`），才需要含 Tkinter 的 Python 3.10+；首次 `start.bat` 会自动调用 `setup.bat` 安装依赖。

---

## 平时怎么更新

1. 微信登录好
2. 双击 `start.bat`
3. 选好通讯录、要更新的表
4. 新表第一次用，填一下开始时间；用过的表一般不用填
5. 点「开始更新」
6. 看结果：打开最新结果 / 查看最新记录

它会另存新表，不会直接改坏你原来那份。

## 第一次连微信（Windows）

本工具沿用你提供的 gh_ui Windows 原流程自动获取密钥，首次登录和管理员授权需要本人操作。现有有效凭据可直接用于日常读取。

1. 双击 `start.bat`
2. 「微信连接设置」选择**实际要登录的同一账号**的数据文件夹或 `db_storage`；可从微信设置的文件存储位置打开。多个账号时必须核对，不能沿用另一账号或另一台电脑的目录。界面显示最近修改时间供核对，不会按排序替你猜选账号。
3. 等聊天同步完成后，从右下角托盘右键微信图标 → 退出
4. 点击 **「自动获取密钥并连接微信」** → UAC 点允许
5. 在 gh_ui 原流程打开的微信窗口登录同一账号
6. 等待凭据保存成功，再正常打开微信并测试群连接

成功之后，日常就不用再初始化了。

## 卡住了

| 情况 | 怎么办 |
|---|---|
| 卡在「正在进入」 | 记录微信版本、发生时间和阶段日志，联系维护人员核对 gh_ui 对此版本的支持；不要反复抓取 |
| 提示微信仍在运行 | 先等同步完成，再从托盘退出；工具不会自动强制关闭微信 |
| Excel 被占用 | 先关掉 Excel / WPS 里那张表 |

还不行：把报错原文发我们；别发 `data/local_data` 文件夹。
